
## DeepSeek 网页端工具箱

脚本功能: LaTeX 公式复制修正 & 会话文件夹 & 消息导航 & 折叠思考

安装地址: https://github.com/sherlocknieh/deepseek-web-toolkit/raw/main/dist/deepseek-web-toolkit.user.js

## Progress 功能进展

- [x] **修复 DeepSeek 网页端 LaTeX 公式复制问题:**

- DeepSeek 网页端复制公式得到的是混乱的文本，而不是 LaTeX 源码。
- 通过注入 KaTeX 官方的 copy-tex 插件，使复制时得到完整的 LaTeX 源码。

- [x] **支持用文件夹管理会话历史**

- 原理是把会话标题改为路径格式, 例如「工作/项目A/讨论」, 然后渲染为文件夹结构, 方便管理和查找。
- 支持拖动会话到文件夹, 支持重命名文件夹, 支持整目录移动。
  - [ ] 支持删除文件夹, 实现批量删除会话;

- [x] **右侧消息导航条**

- 修正 DeepSeek 原生导航条在窄屏时自动隐藏的问题, 让消息导航条始终可见, 并且扩展支持到 ChatGPT / Grok / Gemini / 思畅 AI（sichang.xyz）/ Venice 站点。
- 保持 DeepSeek 原生导航的形态与位置: 会话右侧一列短横线, 悬停展开成提问列表（只列提问, 不列回答）, 点击跳到对应提问; 每条提问右侧另有箭头按钮, 可直接跳到紧随其后的回答。每个站点按自己的页面结构识别消息块, 深色主题自动跟随。

- [x] **默认折叠思考**

- 每次打开对话, DeepSeek 会默认展开思考, 占用较多屏幕空间;
- 改为默认折叠思考: 已完成的思考块自动收起, 正在输出的思考保持展开, 手动点开的块不自动收起。
